# screen-capture-helper

Изолированный высокопроизводительный Node.js/TypeScript модуль на Rust для кроссплатформенного захвата экрана. 
Построен с использованием [NAPI-RS](https://napi.rs/) и библиотеки `screenshots`.

##  Особенности

- **Высокая скорость:** Захват экрана реализован на системном уровне через Rust.
- **Ноль системных зависимостей:** Всё компилируется в один бинарный файл `.node`.
- **Полная поддержка TypeScript:** Типы генерируются автоматически при сборке.
- **Готов к pnpm workspace:** Отлично интегрируется в монорепозитории и локальные связки.

##  Установка

Поскольку этот модуль является локальным компонентом вашей экосистемы, вы можете подключить его через `pnpm`.

### Внутри pnpm workspace (Монорепозиторий)
Добавьте зависимость в нужное приложение (например, `apps/desktop-app`):

```json
{
  "dependencies": {
    "screen-capture-helper": "workspace:*"
  }
}
